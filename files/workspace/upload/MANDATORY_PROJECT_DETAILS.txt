## ЗАПРЕЩЕНО
1. Создавать файлы в src/main/java/com/continentgen/mixin/
   → Mixin вызывал краши, папка и файлы УДАЛЕНЫ.
   → continentgen.mixins.json: "client": [] (пустой)
2. Импорт net.minecraft.world.biome.BiomeAccess
   → НЕ существует в Yarn 1.20.1.
   → Правильно: net.minecraft.world.biome.source.BiomeAccess
3. SimplexNoise / шумовые оверлеи в terrain
   → Вызывают круги-артефакты на поверхности.
4. Удалять override carve() — метод АБСТРАКТНЫЙ в ChunkGenerator.
   → ВСЕГДА override с пустым телом (no-op).
5. DrawableHelper → УДАЛЁН в MC 1.20.1. Использовать DrawContext.
6. DEFAULT_WORLD_SIZE = 300_000 → ВСЕГДА 150_000.

## ОБЯЗАТЕЛЬНО
1. Комментарии в коде на русском.
2. При ошибке: сначала error_list.txt → обновить → потом исправлять.
3. После изменений: python3 check_structure.py — 0 ошибок.
4. Все апдейты ТОЛЬКО в continent-mod-updated/.
5. Проверять что методы вызываемые в ChunkGenerator/BiomeSource
   существуют в MapData.java (рассинхрон = ошибки компиляции).
6. Константы (DEFAULT_WORLD_SIZE, SEA_LEVEL) совпадают во ВСЕХ файлах.
7. BiomeSource.getBiome получает quart-координаты → сдвиг x<<2, z<<2.

## КЛЮЧЕВЫЕ КОНСТАНТЫ
- DEFAULT_WORLD_SIZE = 150_000
- SEA_LEVEL = 63
- MIN_Y = -64, MAX_Y = 320
- OCEAN_THRESHOLD = 255 (< 255 = океан в sea-ocean.png)
- WATER_RED_THRESHOLD = 128 (red < 128 AND alpha > 0 = вода в реках/озёрах)
- 1 пиксель = worldSize / 3000 блоков

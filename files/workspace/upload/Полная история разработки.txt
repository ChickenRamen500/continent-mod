## 1. КОНЦЕПЦИЯ ПРОЕКТА

Fabric 1.20.1 мод для генерации мира из 7 PNG карт размером 3000×3000.
Каждая карта определяет один аспект мира:
- height.png — карта высот (grayscale 0-255)
- temperature.png — климатические зоны (6 цветов = 6 зон)
- humidity.png — влажность (grayscale)
- erosion.png — эрозия (grayscale)
- sea-ocean.png — маска океана (255=суша, <255=океан/глубина)
- map_rivers.png — реки (RGBA: alpha>0 AND red<128 = вода)
- map_lakes.png — озёра (тот же формат)

Координатная система:
  worldX/worldZ = координаты в мире Minecraft
  pixelX = ((worldX + worldSize/2) / worldSize) * imageWidth
  pixelZ = ((worldZ + worldSize/2) / worldSize) * imageHeight
  worldSize — размер мира в блоках (default 150_000)
  1 пиксель = worldSize/3000 блоков (при 150_000 → 50 блоков/пиксель)

Тороидальное замыкание: координаты пикселей оборачиваются через modulo.

### Фаза 3: Проблема кругов-артефактов (26.07.2026)

**Проблема**: На поверхности террейна видны круглые артефакты.
- Круги пропорциональны размеру мира (300к → огромные, 75к → меньше)

### Фаза 4: Проблема рек и озёр (27-28.07.2026)

**Версия 1 ( mountains-follow-height ):**
- Реки/озёра следовали высоте рельефа
- surfaceY = terrainHeight - RIVER_CARVE_DEPTH
- waterSurfaceY = terrainHeight - 1
- Результат: в горах река на высоте 190, дно на 187, вода 1 блок.
- Проблема: горы покрытые 1 блоком воды — невыглядит как река.
- Статус: ❌ ОТКЛОНЕНО

**Версия 2 (SEA_LEVEL approach):**
- Вода рек/озёр на уровне SEA_LEVEL (63)
- Любая местность ниже 63 заливалась водой
- surfaceY = SEA_LEVEL - RIVER_DEPTH, waterSurfaceY = SEA_LEVEL
- Берега: плавный переход через riverNess/lakeNess
- Проблема: на горах (terrainHeight=191, SEA_LEVEL=63) перепад 128
  блоков на ширину ~16 блоков берега
- Пользователь: "перепад в 128 блоков высоты на 16 ширины берега"
- Статус: ❌ ОТКЛОНЕНО — добавлено в ЗАПРЕЩЕНО

**Предложенное решение (Terrain Carving — по аналогии с Tectonic):**
- Русло реки = ПОНИЖЕНИЕ рельефа относительно окружающего террейна
- waterLevel = terrainHeight - CARVE_DEPTH * riverNess
- Вода следует за местностью: река в горах на Y=180, на равнине на Y=70
- Перепад между берегом и водой = фиксированный (3-8 блоков), НЕ 128
- Статус: ⏳ НЕ РЕАЛИЗОВАНО

### Фаза 5: Анализ модов Tectonic и Lithostitched (28.07.2026)

**Tectonic v3.0.17 (Fabric 1.20.1):**
- НЕ использует fluid_level_floodedness/spread для поверхностных рек
- Rivers = 2D ridge noise ВЫЧИТАЕТСЯ из террейна → долины
- sloped_cheese = 4 * quarter_negative(depth + offset * factor)
- quarter_negative(x): x>0→0 (воздух), x<0→-x/4 (твёрдый)
- Точка пересечения = поверхность
- 3 ключевых параметра: continentalness, erosion, ridges
- Nested spline: continents → (erosion → (ridges → height_offset))
- factor = 0.6 (равнины) до 5.6 (горные пики)
- Подземные реки: Y=32-72, ridges<0.2, continentalness>-0.17, erosion<0.37
- barrier=-1 в зонах подземных рек (вода течёт свободно)

**Lithostitched v1.4.11 (Fabric 1.20.1):**
- Библиотека-фреймворк (НЕ провайдер контента)
- Modifier Pipeline: 6 фаз (BEFORE_ALL, MODIFY, ADD, REMOVE, REPLACE, AFTER_ALL)
- WrapNoiseRouterModifier: патчит 15 слотов noise router
- MergedDensityFunction: комбинирует original + wrapped
- ChunkMapMixin перехватывает RandomState.create()

**biomss.pdf — справочник биомов MC 1.20.1:**
- Continentalness: < -0.45 → океан, -0.15..0.1 → берег, >> 0 → материк
- Erosion: низкая → горы, высокая → равнины
- Temperature: -1 → лёд, +1 → жара, +2 → пустыня/badlands
- Реки: при ВСЕХ значениях continentalness (cut valleys)
- Океаны: C < -0.45

## 8. АНАЛИЗ: ПРЕДЛАГАЕМОЕ РЕШЕНИЕ ДЛЯ РЕК/ОЗЁР

Подход "Terrain Carving" (по аналогии с Tectonic):

Для каждой колонки:
  terrainHeight = getHeight(x, z)                    // из height.png
  riverNess     = getRiverNess(x, z)                 // 0..1, билинейная
  lakeNess      = getLakeNess(x, z)                   // 0..1, билинейная

  // Локальная "водная поверхность" — ниже окружающей местности
  waterLevel = terrainHeight - CARVE_DEPTH * max(riverNess, lakeNess)

  // Дно русла ещё ниже (параболическое сечение)
  riverBed = waterLevel - RIVER_BOTTOM_DEPTH * riverNess
  lakeBed  = waterLevel - LAKE_BOTTOM_DEPTH * lakeNess

  surfaceY = max(riverBed, lakeBed, terrainHeight - bankBlend)
  waterSurfaceY = waterLevel

Ключевое отличие от SEA_LEVEL подхода:
- Вода следует за местностью (река в горах на Y=180, на равнине Y=70)
- Перепад берег-вода = фиксированный (3-8 блоков)
- НЕТ перепада 128 блоков

Для берегов:
- bankBlend: плавное понижение в зоне riverNess/lakeNess от 0.2 до 0.5
- Максимальный перепад контролируется через bilinear интерполяцию
